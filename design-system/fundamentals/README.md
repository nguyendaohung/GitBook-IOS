## Câu hỏi phỏng vấn tổng quan

**Q: Kiến thức nền nào quan trọng nhất khi phỏng vấn?** Value/reference semantics, ARC, protocol/generic, closure ownership, lifecycle, layout/cell reuse; giải thích bằng code và lỗi thực tế.

**Q: Foundation và UIKit khác nhau thế nào?** Foundation cung cấp APIs data/network/system, UIKit xây UI; Swift Standard Library cung cấp String/Array/Optional.

**Q: SwiftData @Model, @Observable và @State khác nhau?** Hai đầu là macros (persistent model/observation), @State là property wrapper quản lý UI storage.
