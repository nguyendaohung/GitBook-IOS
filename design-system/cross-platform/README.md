## Câu hỏi phỏng vấn tổng quan

**Q: React Native vs Native iOS?** React Native chia sẻ JS/React UI logic, native modules/SDK và iOS lifecycle vẫn cần hiểu; chọn theo team/feature/performance.

**Q: Power Apps dùng khi nào?** Low-code business workflow/data CRUD; chọn Canvas/Model-driven, connector/delegation/security và ALM.

**Q: Axios khác URLSession?** Axios JS HTTP client, URLSession native Apple; cùng cần status/error/cancellation/auth/retry policy.
